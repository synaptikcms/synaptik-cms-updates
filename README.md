# synaptik-cms-updates

This repository powers the update registry and community contributions for [SynaptikCMS](https://synaptikcms.com) — a lightweight, flat-file PHP CMS with no database.

---

## Contributing a language pack

SynaptikCMS ships with English, French and Spanish. All other languages are community-contributed and listed on the [Language Packs page](https://synaptikcms.com/language-packs/).

**If your language isn't listed yet, you can add it.** See [CONTRIBUTING.md](./CONTRIBUTING.md) for the full step-by-step guide.
